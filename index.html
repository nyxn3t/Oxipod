Oxipod

Put music on your old iPod from Linux. This is Oxipod's own Flatpak repository: add it once, and new releases show up in your software center and with flatpak update. You need Flatpak on your system.

flatpak remote-add --user --if-not-exists oxipod https://nyxn3t.github.io/Oxipod/oxipod.flatpakrepo
flatpak install --user oxipod io.github.nyxn3t.Oxipod

Or open oxipod.flatpakref with your software center.

This is not Flathub. Adding the repository means you trust me, nyxn3t, the author of Oxipod, to ship updates. They are signed with this key, which Flatpak checks for you:

8990 48DA 42D4 FA50 7EC6 F01F A9A4 E497 D0B1 7C45

The same fingerprint is in the README on GitHub, so you can compare the two.

Oxipod should work with the iPod classic, the mini and the nano up to the 4th generation, and so far it has only been tried on a nano 3rd gen (more about which iPods work). Oxipod on GitHub has the source, the releases with a plain .flatpak file, and a place to say how it works on your iPod.
